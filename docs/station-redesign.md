# 更新小站 · 2026-10-13 视觉重设计

## 设计方向

面向从群聊进入的普通手机用户，采用清楚、有辨识度的软件更新站视觉。通过真正的软件图标、设备标签、版本记录建立品牌感，首页突出「找到更新」这一实际任务。

颜色：背景雾蓝 `#F5F7FB`、白色表面 `#FFFFFF`、主文字深蓝 `#18243B`、次要文字 `#626D80`、品牌蓝 `#245BDD`、公告浅杏 `#FFF7E7`。分隔线 `#E3E9F2`，状态文字独立定义。

字体：苹方、微软雅黑与中文系统字体。桌面主标题 44px，手机 28px；正文 16px，辅助信息 14px。版本使用等宽数字。标题与列表统一左对齐。

桌面最大宽度 1120px。顶部品牌与导航之后，用标题解释用途，右侧直接推荐最近一条真实更新。主区域为更新清单和软件快捷入口。公告保持紧凑，主要行动入口有明确轮廓。手机收起推荐区域及侧栏，避免首屏过高。

```text
桌面
品牌                 最新 / 软件 / 公告         管理入口
站点用途标题                       最近更新软件 / 版本 / 设备
置顶公告                                          全部公告
搜索 + 设备筛选                    软件快捷入口
按日期分组的更新                    新手安装步骤
图标 / 软件名 / 版本 / 设备 / 摘要 / 查看更新

手机
品牌                              软件目录入口
标题 + 简介
置顶公告
搜索 + 设备筛选
最新更新
日期 / 完整更新条目
固定 最新 / 软件 / 公告 导航
```

设计审查：首页的推荐直接使用最近发布版本，图标表达影视软件特征，侧栏提供软件直达入口；避免与当前任务无关的大型装饰、宣传数字和重复卡片。示例内容及未配置的获取入口仍明确标记。

## 组件与维护

主样式：`apps/web/app/station-design.css`。保留原样式文件用于对照，页面只加载新版样式，避免叠加覆盖。

图标：上传的软件图标优先；示例软件使用专属 SVG 图形。新建软件使用稳定的默认图标，不依赖随机选择。

交互：延续原有搜索、设备切换、直接分享、复制失败回退、公告有效期与管理发布逻辑。44px 点击区域、键盘焦点和减少动画偏好保留。
