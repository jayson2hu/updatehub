# 更新小站：50 套设计审查

本轮目标是让站主比较不同的信息架构与视觉语言。审查入口为 `/designs`，每个编号都有独立首页、软件目录、软件详情与公告页；读取现有公开数据，不改动发布流程。

## 设计约束

- 软件、设备、版本、日期、可用状态与获取入口是页面主角。演示数据明确标注；没有地址时不模拟可下载。
- 正文采用苹方 / 微软雅黑，16px，辅助文字不低于14px；刊物与人文系列仅在标题使用宋体。版本信息以等宽数字辅助识别。
- 以四至六个核心色建立每套配色：背景、表面、正文、次要文字、强调色、分隔线。明暗状态始终有中文文字。
- 手机以16px边距、44px操作区域设计；桌面最大宽度1120px。广告默认关闭，独立于软件获取操作。

## 布局草图

设备优先：`站名 → 设备入口 → 重要公告 → 日期 / 软件 / 版本 → 底部导航`

更新刊物：`刊头 → 今日重点 | 公告栏 → 按日期编排的更新 → 软件索引`

系统工作台：`导航侧栏 | 搜索 → 设备 / 状态 → 按软件或时间归档的更新`

群友社区：`群站头部 → 置顶消息 → 时间流 / 消息气泡 / 布告 → 导航`

## 设计复核

避免将50套做成相同圆角卡片的换色版本。使用50个独立布局名，分别改变导航位置、刊头形态、公告编排、列表结构、内容密度、软件识别方式与桌面栏数。对影院、未来与图形实验系列限制装饰高度，保留移动端内容入口。完整功能仍由现有主站承担，本轮预览用于选择最终视觉方向。

## 审查建议

优先比较02「设备优先」、08「轻刊」、21「森绿书签」：分别侧重首次访问的效率、长期阅读质感与亲和力。实验性较强的方案用于判断视觉偏好，不默认作为最终上线方案。

## 使用

在设计库中按系列搜索，切换手机或桌面实拍预览；收藏保存在当前浏览器。最多选择4套并排比较。点击「打开方案」后可操作搜索、设备筛选、软件与公告详情、历史版本与复制链接。预览工具栏可跳转上一套或下一套、切换广告位演示；广告演示不更改全站广告开关。
