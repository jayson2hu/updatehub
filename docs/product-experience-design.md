# 产品与体验交付设计

更新：2026-09-26。适用本轮「全部梳理产品和用户体验并完成开发」请求。公告优先的用户指令覆盖原始文档中导航优先的首页；原始文档仍作为功能和工程要求依据。

## 定位与边界

UpdateHub 是面向固定用户群的软件公告与使用服务中心。用户先理解变化，再判断影响，通过可信的官方入口行动；软件档案、历史线和帮助内容为这个过程提供背景。普通用户无需注册。管理员是内容负责人，所有公开内容由其明确确认发布。

不托管安装包，不自动检测电脑，不自动发送聊天、邮件或推送。不把演示版本当作真实新闻。生产上线与真实内容核验属于需要实际环境和运营资料才能验收的交付状态，不能以本地构建替代。

## 任务与信息架构

| 用户任务 | 主入口 | 完成标志 |
| --- | --- | --- |
| 了解近期变化 | 最新公告 | 读懂变化、受影响用户与操作建议 |
| 跟进自己使用的软件 | 我的关注 | 关注持久保存，相关公告集中呈现 |
| 回看某次版本与建议 | 软件档案 / 公告历史线 | 可识别当前版本、正在阅读版本、历史补录 |
| 只记得用途或别名 | 帮我找软件 | 从描述、分类、系统找到软件档案及官方入口 |
| 新电脑 / 首次使用 | 新手开始 | 选择系统和用途，选定软件加入关注并进入公告流 |
| 解决安装和更新疑问 | 帮助中心 | 查到常见问题、操作指南、软件专属帮助 |
| 按场景整理软件 | 软件合集 | 理解每个成员的理由，选择性批量关注 |
| 发布和维护内容 | 管理工作台 | 草稿、预览、人工发布、下线、审计闭环 |
| 改进内容 | 管理工作台 | 从实际搜索无结果与官方点击聚合找到维护任务 |

主导航保留「最新公告 / 我的关注 / 软件档案」，增加「帮助中心」；新手引导和 Finder 通过首页侧栏、软件页和帮助页提供情境入口。手机菜单可键盘操作，关键信息和行动不依赖侧栏。

## 关键体验约束

- 公告首页不被推荐软件和教程挤占；辅助任务以紧凑入口出现。
- 每条公告回答「变化、影响、行动」，历史建议明确为当时建议。
- 软件详情在首屏给出当前记录与官方入口，并连接历史、公告和软件专属帮助。
- Finder 根据真实软件资料匹配，不猜测未收录软件。没有结果时保留搜索条件并给出重新选择的入口。
- 新手流程为系统 → 用途 → 选择软件，支持返回修改；不会自动关注推荐名单，用户确认后才保存。
- 合集仅展示公开软件；推荐理由来自管理员。已关注软件不重复添加；保存受限时说明仅当前页面有效。
- FAQ 使用问题作为入口，答案可直接展开，关键词与分类可组合。指南按可读段落展示，允许复制链接。
- 管理表单按内容类型组织字段，关键错误在操作附近展示。保存与发布分离，后台预览必须与公共内容结构一致。
- 空状态说明下一步；网络失败可重试且不抹掉输入；404提供返回路径。统一可见焦点和至少44px的主要操作区域。
- 统计用于内容改进，仅保留必要的聚合信息，不记录个人账号、设备指纹或精确位置。不能将浏览事件计数宣称为独立用户或实际问题解决率。

## 视觉方案与复核

色彩沿用品牌记忆：白色 #FFFFFF（阅读底色）、雾灰 #F5F7F8（辅助区域）、墨蓝 #203039（正文）、深青 #147D70（行动）、浅青 #EAF5F1（选中与当前状态）、琥珀 #996415（需注意信息）。危险/暂缓等级保留既有语义色。

中文优先 Microsoft YaHei / PingFang SC，西文使用 Arial。正文15–16px，辅助信息13–14px，标题28–34px；长文行宽约40个汉字，行高1.9。全部主要内容左对齐，侧栏承担下一任务而非重复正文。

```text
公告首页                         帮助中心 / Finder
品牌  最新公告  关注  软件  帮助  标题 + 对当前任务的简短解释
标题 + 按软件查看 / 我的关注      搜索 / 系统或用途选择
搜索与筛选          我的关注     主内容（问答/步骤/匹配软件）
公告列表            新手开始     后续入口（官方 / 关注 / 公告）
分页                使用帮助

新手开始
选择系统 → 选择用途 → 勾选软件 → 查看我的关注
              可返回修改           真实保存反馈
```

复核：不增加宣传大横幅、虚构计数、装饰英文或均匀堆叠的营销卡片。公告采用连续阅读列表，FAQ采用展开行，指南采用文章，合集采用可选择的软件清单；布局形式由任务决定。原先扩展功能继续延期的计划已被本轮完整开发范围取代。
