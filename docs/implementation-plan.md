本轮依据用户要求，已将原先延期的 Finder、新手引导、指南、FAQ、合集和运营工作台纳入实现范围。产品和视觉决策见 `product-experience-design.md`，本轮实际验证结果见 `full-product-test-report.md`。下方此前轮次记录仅用于追溯。

1. 保留公告优先：最新公告、关注流、当前版本、历史记录与官方入口仍为主线。
2. 完善新用户任务：用途/描述 Finder → 系统与用途引导 → 选择软件 → 持久关注 → 查看相关公告。
3. 完善帮助内容：指南、常见问题、场景合集均由数据库和管理员维护；公开页搜索、筛选、分页、详情、软件关联、合集选择关注。
4. 完善运营流程：后台工作台、三类内容可视化编辑、草稿恢复、预览与人工发布、下线与归档、真实搜索与官方入口聚合统计。
5. 加强交付：数据库迁移、受控种子资料、内容隔离/发布/API测试、完整浏览器任务、真实PostgreSQL和备份恢复、构建、CI、部署说明及健康监测。

完整开发不包括原始需求中的 V2/V3 自动版本检测、AI公告、普通用户账号或自动外发；这些仍是明确的非首版范围。生产域名/TLS/部署和真实内容核验须在实际条件具备后验收，不能以本机通过代替。

## 历史计划（2026-09-22）

原始范围依据 `master-specification.md` 第 122 节。用户随后明确产品应以公告为核心，当前信息层级与发布范围以 `product-positioning.md` 为准。首轮软件导航任务已形成基础，以下将历史交付与当前公告迭代分开记录，不将生产准备标记为完成。

## 当前迭代：公告中心

1. 内容模型：新增 `release_update`，兼容版本更新、使用提醒与维护通知；迁移从首轮版本升级并保留原有软件 / 管理数据。
2. 发布规则：草稿→可选待审核→人工确认发布→归档；保存与发布分离，部分更新仍校验完整发布条件；版本、公告与审计同事务处理。
3. 公告管理：起草、预览、审核、人工确认发布、修改、归档、置顶与群通知复制。复制只是生成供管理员粘贴的文案，不自动发送消息。
4. 用户入口：首页 / 公告列表优先，详情强调影响、行动、变化与来源；“我的关注”优先显示软件公告，软件档案保留查询与官方入口。
5. 验证：API 状态与数据隔离、旧版本保护、排序、真实 PostgreSQL 迁移、前端构建、桌面与手机浏览器闭环。

具体条件见 `announcement-acceptance.md`，实际结果见 `announcement-test-report.md`。公告迭代与首轮分别验收，未运行的检查不沿用首轮通过结论。

## 首轮阶段及验收（历史）

1. 基础工程：npm workspace、Next.js / TypeScript、FastAPI、SQLAlchemy、PostgreSQL、Alembic、Docker Compose。验收：依赖安装、数据库迁移、health / ready、前端构建。
2. 软件数据：software / category / alias / tag / platform / official_link、种子数据、公开查询及筛选。验收：名称 / 别名 / 用途搜索、分页、未发布内容隔离、URL 校验。
3. 管理闭环：Argon2id、HttpOnly session、CSRF、登录限流、后台 CRUD、分类管理、图标上传、审计。验收：未授权拦截、登录退出、新建修改下线软件、官方链接维护。
4. 公开界面：首页、软件列表、详情、用途导航、轻量本地关注。验收：服务端真实数据、可操作筛选、错误空状态、官方跳转、新标签与来源提示。
5. 集成交付：API / 安全测试、TypeScript / lint / build、Playwright 桌面及 375px / 393px、截图检查、README 与部署说明。

每一阶段先验证再集成。不引入 AI、自动版本检测、主动消息发送、普通用户账号和广告系统。不托管软件安装包。演示版本和公告明确标注为示例，不声称为实时最新官方版本或已核实新闻。

## 设计计划

- 色彩：白色 #FFFFFF，雾灰 #F5F7F8，墨蓝 #203039，深青 #147D70，浅青 #EAF5F1，琥珀 #A36B20。更新语义保留红 / 绿 / 黄 / 中性灰。
- 字体：系统中文使用 Microsoft YaHei / PingFang SC；英文与数字使用 Arial。标题用字重与紧凑行高建立层级，不添加装饰英文标签。
- 布局：首页主栏依次显示置顶与最新公告，搜索 / 筛选服务于公告阅读；侧栏解释重要程度、关注关系和软件档案。手机变单列，关键信息与操作保持触达。
- 特征：围绕“是否影响我、应该做什么”组织公告摘要和详情，软件图标用于识别关联对象，避免将软件推荐重新变为主视觉。
- 复核：不采用渐变、虚构计数、假更新动态或不可用导航。首页每个入口都连接真实功能。

## 环境和验证记录

当前机器有 Node.js 24、Python 3.14，没有 Docker CLI。PostgreSQL 是部署默认数据库；本地预览可显式使用 SQLite，不能将 SQLite 验证等同 PostgreSQL 集成验证。首轮结果保留在 `test-report.md`，公告迭代写入 `announcement-test-report.md`。
