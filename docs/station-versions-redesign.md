# 版本下载、广告基础与全站重设计

2026-10-15。本轮沿用 Next.js / FastAPI / SQLAlchemy，保留现有软件入口、数据库和图片。

## 设计取舍

颜色：背景 #F5F7FB，白色 #FFFFFF，正文 #18243B，辅助 #626D80，品牌 #245BDD，边线 #E3E9F2。状态使用独立的绿/琥珀/红色并始终配文字。

字体：苹方、微软雅黑等系统字体。手机正文 16px，辅助 14px，主标题 26–28px，版本号使用等宽数字排列。桌面最大内容宽度 1120px。

布局：所有内容左对齐，图标用于快速识别软件，日期分组用于理解更新顺序。首页不用大型宣传区，首屏留给真实更新。

```text
手机首页                 软件详情                   管理后台
站名 / 软件目录          图标 / 名称 / 分享          工作台 / 分类导航
简短介绍                 有效重要公告               标题 / 主要操作
置顶公告 / 全部公告       选择设备                   版本、下载来源与提取码
搜索 / 设备              版本下载（新版 + 旧版）    安装提醒 / 预览
日期 / 软件更新          更新内容 / 独立获取入口     草稿 / 发布 / 分享
最新 / 软件 / 公告       安装 / 常见问题            广告素材 / 时间 / 开关
```

对方案的复核：去掉通用的巨大标语、重复指标与装饰性渐变，改用软件图标和日期表达站点性质；详情不再把可下载旧版藏在折叠记录里。后台使用深蓝导航与明亮表单区，让内容编辑和发布操作有清晰边界。360px 长软件名的实际截图发现首条更新略被底栏挡住，已将全部公告并入公告区域，减少一行占用。

## 多版本

数据仍使用独立版本记录和独立链接表。每个设备都可有多个已发布版本；版本选择器清楚标出最新版/历史版、日期、可获取/未配置链接/暂不可用。选中旧版后，说明、状态、来源、链接、备用入口、提取码、安装提醒和手机固定栏同步切换。`?platform=tv&release=<id>` 支持直开、刷新和分享。

后台增加按软件、设备筛选，以及最新版/历史版与链接数量。新建版本可沿用上一版，但明确提示核对本版地址。将某版设为暂不可用会关闭该版的获取按钮；撤回隐藏该版；其他版本不受影响。示例软件继续不提供真实下载地址。无效或未公开版本参数会提示并显示所选设备的最新版。

## 广告

广告与推广管理已可使用：草稿、预览、上线/撤回、封面上传、活动正文/按钮、独立目标链接、投放位置多选、开始/结束时间，以及广告总开关。默认关闭，主站保留关闭状态。结束时间必须晚于开始时间；上线必须有安全的 HTTP(S) 活动链接；图片只允许上传后返回的本站路径。全部管理写入均验证登录与 CSRF。

展示位置为 `home_feed`、`detail_body`、`desktop_sidebar`。同一位置按分享链接标识排序选择第一条有效内容。首页在第三条更新后插入，详情在获取区域之后插入，桌面侧栏独立放置。未启用/过期/图片失败自然收起；图片按 16:9 预留尺寸并在接近屏幕时加载；打开页面期间到期也会收起。

`apps/web/lib/advertising.ts` 提供 `AdProvider` 和 `AdPlacement` 契约；`components/station/ad-slot.tsx` 是统一接入边界。第三方广告平台、点击统计、计费和下载前中转尚未接入。后续接服务需要配置供应商及 CSP，继续保持推广链接与下载链接分开。`/promo/<slug>` 独立分享，过期页面保留结束状态；关闭总开关或撤回后不公开。

## 兼容与运行

旧 A/B/C 预览路径自动跳转到新版对应路径，保留所选设备/版本；正式软件和公告分享地址保持不变。启动、管理员初始化、发布与备份见 [运营文档](station-operations.md)。本轮无新增数据库字段，不需要额外数据迁移。
