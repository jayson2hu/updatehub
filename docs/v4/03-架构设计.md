## 1 总体结构

```text
浏览器 / 微信小程序 / 小红书小程序
        │  GET  /api/v1/station/*          （公开读取，服务端组件 + 小程序）
        │  POST /api/v1/station/feedback|wishes|sync-codes|events（匿名写入）
        ▼
Next.js 16（apps/web，SSR + 客户端交互）── 同源转发 /api/v1 → FastAPI
        │
FastAPI（apps/api）── StationService（内容） / station_engagement（反馈、想要、同步码、统计、工作台）
        │
SQLAlchemy 2 + Alembic ── PostgreSQL 17（生产）/ SQLite（本机开发）
```

- 公开读取继续以 `GET /station/data` 一次返回全量（站点设置、软件、版本、公告、推广、统计摘要），网页和小程序在客户端筛选。数据量是几十款软件、几百条版本，这种方式足够。
- 旧版 UpdateHub 的路由和表保留，由 `LEGACY_ENABLED` 开关控制（ADR-0002，M6 实施）。

## 2 数据模型（ERD）

```text
station_software 1 ──< station_release 1 ──< station_release_link
      │                     │  └─ stable_release_id ─> station_release（自引用，SET NULL）
      │                     ├──< station_feedback_daily  (release_id, day) PK
      │                     └──< station_feedback_issue ─> station_release_link（SET NULL）
      ├──< station_announcement_software >── station_announcement
      └──< station_wish.software_id（SET NULL，收录后关联）
station_settings（单行 id='site'）   station_promotion   station_sync_code   station_stats_daily (day,event,key) PK
```

### 2.1 本期新增字段

| 表 | 字段 | 说明 |
|---|---|---|
| station_software | `category` | video / netdisk / tool / music / note / reading / browser / other，默认 other |
| | `description` `developer` `website_url` `tags` | 详细简介、开发者、官网（`safe_url` 校验）、标签 ≤20 |
| | `install_guides` | `{platform: [步骤]}`；原 `installation` 作为通用步骤保留（兼容旧小程序） |
| | `favorite_count` `view_count` | 累计计数（估算，ADR-0005），只由统计上报维护 |

| station_release | `advice` `advice_note` | 更新建议四档（ADR-0003） |
| | `stable_release_id` | `advice=hold` 时必填，必须是同软件、同设备、已发布的其他版本；advice 改为其他值时自动清空 |
| | `changes` | `[{kind: added/fixed/improved/known_issue, text}]` ≤50 |
| | `release_date` `package_size` `requirements` | 官方发布日期、安装包大小、系统要求 |
| station_release_link | `kind` `is_active` | official / netdisk；入口是否有效 |
| station_settings | `ad_placements` | `{placement: bool}`，缺省视为开启；总开关 `ads_enabled` 仍优先 |
| | `footer_note` `icp_number` `notice_tip` `inapp_hint` | 页脚、备案号、群通知末尾提示、应用内打开提示 |
| | `hot_searches` `about_text` `privacy_text` `disclaimer_text` `admin_nickname` | 热门搜索词（≤8）、三段说明正文、工作台问候昵称 |

### 2.2 本期新增表

| 表 | 主键 | 用途 | 保留 |
|---|---|---|---|
| station_feedback_daily | (release_id, day) | 每版本每日"能用 / 有问题"计数 | 长期（纯计数） |
| station_feedback_issue | id | 问题明细：类型、说明（过滤联系方式，≤300）、关联入口、处理状态 | 180 天 |

## 3 接口契约（新增 / 变更）

前缀 `/api/v1`。错误统一为 `{"detail": "中文说明"}`，校验错误的字段名通过 `FIELD_LABELS` 转成中文。

### 3.1 公开读取（只加字段，不改名）

| 接口 | 变化 |
|---|---|
| `GET /station/data` | `software[]` 增加 v4 字段以及 `favorite_count`、`view_count`；`releases[]` 增加 v4 字段以及派生的 `previous_version`、`feedback_ok`、`feedback_issue`；`settings` 增加 v4 字段；推广的 `placements` 会去掉已关闭的位置，全部关闭的推广不再返回；新增 `stats = {software: {id: {views_7d}}, hot_software: [id×≤5], hot_searches: [≤8]}` |
| `GET /station/software/{slug}` | `releases[]` 同上，带派生字段 |

### 3.2 匿名写入

所有匿名写入都先检查请求来源（`check_origin`），再按 IP 在进程内存里限流（IP 只用作内存中的计数 key，不写库）。

| 接口 | 请求 | 响应 | 限流 |
|---|---|---|---|
| `POST /station/feedback` | `{release_id, verdict: ok\|issue, kind?, note?, link_id?}`；`verdict=issue` 时必须带 `kind` | 204；版本未发布返回 404；入口不属于该版本返回 422 | 与想要的软件合计 20 次/小时 |
| `POST /station/wishes` | `{name≤60, platforms?, note?≤300}` | 201 `{votes, status}` | 同上 |
| `POST /station/sync-codes` | `{software_ids≤200, device?}` | 201 `{code, software_ids, device, expires_at}`，只保留已发布的软件 | 10 次/小时 |
| `GET /station/sync-codes/{code}` | 忽略大小写、空格和短横线 | 200，同上（过滤掉已下架的软件）；过期或不存在返回 404 | 30 次/小时（防暴力猜码） |
| `POST /station/events` | `{events: [{event, key}] ≤30}` | 204；未知 key 静默丢弃，未知 event 返回 422 | 240 次/分钟 |

允许的事件及其 key：
- `page_view`：页面名，取值为 home / library / detail / announcements / announcement / search / me
- `sw_view`、`fav_add`、`fav_remove`：软件 id
- `dl_copy`：版本 id
- `ann_view`：公告 id
- `ad_imp`、`ad_click`：`{placement}:{promotion_id}`
- `search`、`search_miss`：搜索词，经过 `safe_query` 过滤

### 3.3 后台（会话 + CSRF；写操作写审计日志）

| 接口 | 说明 |
|---|---|
| `GET /admin/station/dashboard?days=1..90`（默认 7） | `series` 按日数据（访问、下载、能用、有问题、新增收藏），`totals`（含上一周期的访问和下载，用于计算环比），`counts`（徽标数字），`hot_releases`（有问题最多的前 5 个版本，附问题类型分布），`broken_links`，`wishes`（前 5），`recent_releases`（8 条），`ads`（各广告位开关、曝光、点击），`promotions`（各推广的曝光和点击） |
| `GET /admin/station/feedback?status=&kind=&software_id=` | `{items: 问题明细≤200, releases: 近 7 天按版本汇总}` |
| `PATCH /admin/station/feedback` | `{ids≤200, status: new\|handled\|ignored}`，可批量 |
| `GET /admin/station/wishes?status=` | 按票数排序，最多 300 条 |
| `PATCH /admin/station/wishes/{id}` | `{status, software_id?}`；`status=added` 时必须关联软件 |
| 原有 software / releases / announcements / promotions / settings | 接受上述新字段；不认识的字段仍返回 422（`extra="forbid"`） |

## 4 安全与隐私

- 匿名写入的防护：检查请求来源，加进程内限流（只在单 worker 下有效，部署文档需注明），文本限长，过滤联系方式（邮箱、网址、电话、微信/QQ 号）后替换为"［已隐藏］"。
- 不保存 IP、UA、设备指纹、会话或访客 id。统计只存计数。
- 后台写操作沿用 `WriteAdmin`（会话 + `X-CSRF-Token` + 来源检查），并通过 `CatalogService.audit` 记录。
- 统计写入失败只回滚、记一条不含内容的告警，不影响访客的正常请求。
- 同步码字符集去掉了易混字符，10 位约 50 bit 熵，再加上恢复限流，足以防暴力猜码。

## 5 Web 前端结构（M3/M4）

| 层 | 位置 | 说明 |
|---|---|---|
| 样式 | `app/station-v4.css` | 根类 `.sv-site`，前缀 `sv-`；token 取自设计稿 |
| 数据 | `lib/station.ts`、`lib/station-types.ts` | 服务端 `getStationData()` 通过 `cache` 去重；类型与后端 schema 对齐 |
| 本地状态 | `hooks/local-store.ts`（由 `use-my-software.ts` 抽出） | 收藏、最近看过、常用设备、已反馈、已读红点；localStorage 不可用时退回内存 |
| 上报 | `lib/station-events.ts` | 批量、空闲时发送；同一软件每天在本地去重 |
| 组件 | `components/station/*` | 外壳、卡片、详情标签页、Sheet、Toast、分享海报（canvas）、二维码 |
| 后台 | `components/station-admin/*` | 分组导航、工作台、快捷发布、反馈、想要的软件、广告位统计 |

路由：`/`、`/software?cat=&sort=`、`/software/[slug]?platform=&release=`、`/announcements?type=`、`/announcements/[slug]`、`/search?q=`、`/me`（robots 不收录）、`/promo/[slug]`、`/about`。

## 6 小程序结构（M5）

- 源码在 `apps/miniprogram`，由 `scripts/build-miniprograms.cjs` 生成 `miniprogram-wechat` 和 `miniprogram-xhs` 两份。
- `utils/api.js` 增加 POST。收藏和同步码用 `wx/xhs` storage 保存。下载入口一律"复制链接"，并上报 `dl_copy`。
- 页面：latest（首页）、software（软件库）、detail、announcements、announcement、search、me。
