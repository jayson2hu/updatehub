# ADR-0008：触控区域与辅助文字可读性

日期：2026-10-19。配套：[UI 规范 v1.1](../02-UI设计规范.md)、[测试与验收](../05-测试与验收.md)。

## 问题

实际浏览器测量发现搜索输入与清空按钮高度、返回按钮宽度只有 40px；辅助文字和首页部分小字对比度不足。手机用户经常需要辨认日期、设备与搜索提示，这些内容不能因为视觉弱化而难以阅读。

## 决定

保留现行 v4/v5 布局，搜索输入、清空和返回按钮点击区至少 44px，搜索输入字号 16px。Web 辅助色 `--sv-ink3` 改为 #626F84，底栏文字和搜索提示使用相同变量。首页渐变改为 `linear-gradient(125deg,#1F4FD8,#315FDA 65%,#4169CD)`；统计胶囊浅蓝底 #EBF1FF、深蓝字 #1F4FD8；桌面公告底 #2149B3，白字不设透明度。

同步修改 `apps/miniprogram` 共用样式、底栏颜色和首页/搜索页；搜索输入 32rpx 并保留至少 44px 的点击区域，再生成微信与小红书开发包。两端不得手工修改生成文件作为唯一来源。

## 实际验证

| 文字与背景 | 对比度 |
| --- | --- |
| 辅助字 / 白底 | 5.09:1 |
| 辅助字 / 页面底 | 4.71:1 |
| 搜索提示 / 输入底 | 4.62:1 |
| 首页统计 | 5.86:1 |
| 首页公告 | 7.87:1 |

浏览器脚本在 360/390 下测量首页、目录、搜索、详情及「我的」重要控件，计入伪元素扩展点击区，未发现小于 44px 的目标；对上述指定文字计算对比度。完整浏览器检查 17 组通过、29 张截图，另有日常站点 6 张只读截图，首页、详情、后台等关键页面已实际打开审查。最终两套 Web 构建和小程序 50 项逻辑检查通过。

这不是全站 WCAG 审计。小程序仅共用源码、生成与逻辑验证，原生字体渲染、真机安全区及微信/小红书实际宿主仍待验；Android/iPhone UA 模拟不等于真实设备。
