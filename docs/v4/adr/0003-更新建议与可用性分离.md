# ADR-0003 "更新建议"与"可用性状态"分开存储

- 状态：已采纳（2026-10-18）

## 背景
现有 `status`（normal/attention/unavailable）表示"能不能用、能不能拿到"；`unavailable` 会隐藏全部获取入口。v4 的"更新建议"表示"要不要升级"，其中"先别更新"仍需提供推荐稳定版下载。

## 决策
- 版本新增 `advice`：`recommended` 建议更新 / `wait` 可以等等 / `hold` 先别更新 / `optional` 可选；附 `advice_note`。
- 新增 `stable_release_id`（自引用，删除时置空）；`advice=hold` 时必须指定，且须为同软件、同设备、已发布的版本。
- 迁移默认值：`status=attention` → `wait`，其余 → `optional`。
- `status` 语义不变，继续控制可用性与入口展示。

## 后果
前台主按钮规则：`hold` 时显示"下载稳定版 x.y.z"；`unavailable` 时仍不显示入口。小程序同步此规则。
