# ADR-0001 默认站名改为"版本喵"

- 状态：已采纳（2026-10-18）
- 决策人：产品负责人（用户）

## 背景
v4 设计稿提供了"叮！新版"、"版本喵"等候选站名，现有数据默认值为"更新小站"。

## 决策
默认站名使用"版本喵"。站名仍保存在 `station_settings.site_name`，后台"站点设置"可随时修改。

## 影响
- 种子数据、新库默认值改为"版本喵"；现有库通过数据迁移更新，仅当值仍为"更新小站"时才改，不覆盖人工修改。
- 小程序中写死"更新小站"的位置（`app.json` 导航标题、分享标题、`listing-page.js` 默认文案）改为读取站点设置；导航标题等无法动态化的位置使用"版本喵"。
