# ADR-0005 统计口径与隐私边界

- 状态：已采纳（2026-10-18）

## 决策
- 新建 `station_stats_daily`（日期、事件、key、计数），只存按日聚合计数，不存 IP、设备指纹、会话或访客标识；保留 90 天，写入时与每日任务中清理。
- 访问、浏览由客户端主动上报（同一软件每日本地去重后只报一次），不以 `GET /station/data` 计数（小程序有缓存）。
- 收藏数由添加/取消收藏事件累加净值得出，"看过人数"为按天去重的次数，后台均标"约"。
- 反馈、想要的软件、同步码等匿名写入接口：`check_origin` + 进程内限流（IP 仅作为内存 key，不落库）；文字说明过滤联系方式、限长。
- 进程内限流只在单 worker 部署下有效，部署文档注明。

## 后果
无法精确按人去重；换来不需要用户账号、不收集个人信息。

## 补充（2026-10-18，实现时确定）
- 按日统计使用**北京时间**自然日（`app/services/station_engagement.py: today()`）。
- 累计看过与收藏存于 `station_software.view_count` / `favorite_count`，仅为计数，不受 90 天限制；收藏净值不会小于 0。
- 问题反馈明细自提交起保留 180 天；同步码到期即删；均在启动和每日零点清理任务中执行（`services/retention.py`）。
- 统计上报只接受已知事件；软件、版本、公告、广告的 key 必须指向现存内容，搜索词经 `safe_query` 过滤，其他一律丢弃。
