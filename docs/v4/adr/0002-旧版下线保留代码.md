# ADR-0002 旧版 UpdateHub 下线，代码保留

- 状态：已采纳（2026-10-18）

## 背景
仓库中仍有旧版 UpdateHub 的页面、接口与数据表（帮助中心、指南、FAQ、合集、旧公告、旧后台等），与新版"我的""公告"语义重叠，并通过根布局全局加载样式。

## 决策
本期下线、不删除：
- Web 新增 `proxy.ts`，由环境变量 `LEGACY_ENABLED`（默认关闭）控制，旧前台路由与旧后台页返回 404。
- API 旧路由按同一开关挂载，默认不挂载。
- 旧数据表保留，不做删除迁移。
- 旧样式从根布局移到旧页面自身。
- 旧测试标记为 legacy，不进入默认测试集。

## 后果
可随时打开开关恢复旧版；后续版本再评估彻底删除（届时先完整备份数据库）。
