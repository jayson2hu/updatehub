# ADR-0006：匿名凭据、同步码与教程数据迁移

日期：2026-10-19。状态：已实施。补充 ADR-0005，不引入访客账号。

## 反馈与匿名数据

反馈改用 `POST /station/feedback/vote`：服务端返回 HMAC-SHA256 签名凭据，本机保存凭据后才能改投、撤销或补充说明。改投一减一加；消费后的凭据摘要进入 `station_feedback_spent`，重放、跨版本和篡改均拒绝。凭据可修改范围为最近 90 天，调整原票时扣回原日期；统计按北京时间自然日汇总。补充说明不再次计问题票，渠道分别记录 `web`、`wechat`、`xhs`。旧反馈接口仅保留兼容。

服务端不建立持久访客 ID。限流地址只留在进程内存，不写入业务库；默认关闭 API 访问日志，反向代理同样不得记录同步码 URL 或访客地址。备注中的联系方式会脱敏。

`STATION_SIGNING_KEY` 是签名用途的专用密钥，与管理员会话、AppSecret 无关。正式环境必须配置至少 32 个随机字符，缺失时拒绝启动；建议生成 32 字节随机十六进制值。开发环境自动保存在上传目录的父目录 `station-signing.key`，不要删除、提交或输出。

多实例必须使用同一持久密钥。轮换会使旧反馈凭据失效，用户需要重新反馈；计数不会清空。正式环境的密钥从安全密钥库备份，本地备份脚本会收录开发密钥。

## 收藏同步码

码为 10 位随机字符，忽略空格、短横线及大小写，展示为 `XXXXX-XXXXX`。有效期 30 天；服务端只保存 SHA-256 摘要、公开软件 slug 与常用设备，不保存可读码或登录信息。重新生成时传入前码，使前码立即失效。软件下架后不会恢复到收藏中。

网站和小程序按完整「收藏 ID 集合 + 常用设备」比较同步缓存，防止收藏数量相同、内容不同仍展示旧码。

迁移 `40c28a9e6d31` 会将既有码原地散列，升级后原码仍可恢复。降级无法恢复明文，因此只清空同步码表；需通知用户重新生成，软件、版本、反馈与上传不受此步骤影响。升级前先备份，不对在线库直接降级。

## 收录请求

请求返回稳定 ID，可查询状态；合并后原 ID 解析到目标请求，人数、设备票数和最近三条用途合并。「已收录」必须关联已上架软件，防止群友得到无法打开的入口。再次下架后不公开软件 slug。

## 教程及统计迁移

`d13c8e2a4f90` 新增软件收费说明、收录日期、按设备的步骤配图与提示，以及版本/公告浏览计数。配图只能引用本站真实上传路径，步骤索引为 0–29。表单过滤空步骤时同步重排配图索引。

该迁移只增字段；降级会丢失这些新增字段的内容及计数，不删除已上传图片。建议先在独立恢复库验证再安排切换。迁移 roundtrip 与 PostgreSQL 离线 SQL 检查已纳入自动测试；本轮未执行生产 PostgreSQL 在线迁移。
