## 3 布局

### 3.1 断点

| 名称 | 宽度 | 布局 |
| --- | --- | --- |
| 手机 | < 768px | 顶栏 52px + 内容 + 底栏；单列；所有设计以 375 为基准，需在 360 与 390 验证 |
| 过渡 | 768–1023px | 电脑导航 + 单列（右栏内容移到主栏末尾）；分类一行可横滑；软件库 3 列 |
| 电脑 | ≥ 1024px | 电脑导航 + 双栏 |

设计稿只画了 375 与 1120 内容宽两种；过渡区为本规范补充。

### 3.2 电脑布局

- 内容最大宽 **1120px** 居中，内边距 `24px 28px 30px`（`.dbody`）。
- 双栏 `grid-template-columns: minmax(0,1fr) 336px; gap: 24px; align-items: start`（`.two`）。
- 右栏 `position: sticky; top: 84px`（导航 64 + 20），内部纵向 `gap: 16px`。
- 窄页面最大宽：公告列表、搜索 820；我的 860；公告详情 760。
- 顶部导航 64px 高、吸顶、`rgba(255,255,255,.96)` + `backdrop-filter: blur(8px)`，下边线 `--line`；导航内 `gap: 20px; padding: 0 28px`。
- 页脚：白底、上边线，内容同 1120 宽，内边距 `22px 28px`，13px `--ink2`。

### 3.3 手机布局

- 结构自上而下：顶栏（52px，白底，下边线）→ 小红书提示条（可选）→ 滚动内容 → 详情底部操作条（可选）→ 底栏（4 列，按钮最小高 54px，底部 6px + 安全区）。
- 横滑容器 `.hs`：`margin: 0 -14px; padding: 2px 14px 4px`，`scroll-snap-type: x mandatory`，隐藏滚动条。横滑必须限制在容器内，不得撑宽页面。

### 3.4 后台布局

- 网格 `220px 1fr`，最小高满屏。侧栏 `#141F33`，内边距 `18px 12px`。主区 `--bg` 背景，内边距 `24px 28px`。
- 工作台 KPI 4 列 `gap: 14px`；下方 `.agrid` 两列 `1.4fr 1fr`，`gap: 16px`。
- 后台最小支持宽度 1280。

### 4.1 按钮（`.btn`）

| 变体 | 类名 | 样式 | 用途 |

| 尺寸 | 高 | 内边距 | 字号 | 圆角 |
| --- | --- | --- | --- | --- |

| 大 `lg` | min 52 | 0 16 | 16 | 14 |

### 4.2 建议标签（`vtag`，基于 `.tag`）

| advice | 类名 | 底 / 字 | 内容 |
| --- | --- | --- | --- |
| recommended | `sv-tag--ok` | `--ok-soft` / `--ok` | `✓ 建议更新` |
| wait | `sv-tag--warn` | `--warn-soft` / `--warn` | `! 可以等等` |

| optional | `sv-tag--opt` | `#EEF1F6` / `--ink2` | `○ 可选更新` |

## 5 页面结构

以下按从上到下的区块顺序描述；括号中为需求编号。

### 5.1 全站外壳

- 手机：顶栏（R-GLOBAL-02）→ 小红书提示条（仅首页、详情，R-GLOBAL-06）→ 内容 → 详情底部操作条 → 底栏（搜索页无底栏）→ 页脚在内容末尾。
- 电脑：导航（R-GLOBAL-03）→ 内容（`.dbody`）→ 页脚（R-GLOBAL-04）。

### 5.2 首页（R-HOME）

手机：
1. Hero（14px 外边距）：小字「{站名} · 10月第3周」（13px 85% 透明度）→ 主标题 24px →统计胶囊（12px，`rgba(255,255,255,.16)` 底，圆角 8，内边距 2/9，gap 8 可换行）→ 伪搜索框（白底，最小高 44，圆角 12，14px `--ink3`，上 14）。
2. 群公告：标题 +「全部 ›」，横滑 `.annc`。
3. 收藏的软件有更新（有时）：标题 + 角标 +「全部已读」，横滑 `.favc`。
4. 分类宫格。
5. 最新更新：标题 +「软件库 ›」→ 设备 chips → 上 6 → 列表（日期分组、`.rc`、第 3 条后广告）。
6. 本周热门（`.card` 包裹 `.rank` ×5）。
7. 页脚。

电脑：
1. Hero 两栏 `1fr 360px`，gap 30，内边距 34/36，圆角 24；主标题 34px，伪搜索框高 52 / 15px；右栏 `.hero-side`（`rgba(255,255,255,.12)` 底、`rgba(255,255,255,.18)` 描边、圆角 16、内边距 14）标题「📌 置顶公告」+ 最多 3 行。
2. 分类一行（上下 20）。
3. 双栏：主栏「最新更新」（20px）+「共 N 条」→ 设备 chips → 列表；右栏「⭐ 我的收藏」卡（最多 4 行）→「🔥 本周热门」卡 → 侧栏广告。

### 5.3 软件库（R-LIB）

- 手机：分类 chips → 计数与排序行（13px，上 12 下 10）→ 2 列网格 gap 10 → 页脚。
- 电脑：H1「软件库」28px → 说明（`--ink2`，下 14）→ 分类 chips → 计数与排序 → 3 列网格 gap 14。
- 分类：9 个分类 + 全部在 chips 中横滑；首页宫格新增「其他」后为 9 格：手机 4 列（3 行，最后一行 1 格）——建议改为隐藏无软件的分类或把「全部」放第一格；电脑改为 `repeat(9,1fr)`（待产品确认）。

### 5.4 软件详情（R-DETAIL）

手机（`.sec` 依次）：
1. 头部：图标 64 + 分类 · 开发者（12px）+ H1 21px + 简介 13px；关键数字 3 格；结论条。
2. 下载卡（`.card`）：「选择你的设备」+「已自动识别」→ 设备格 → 版本条（或 12px 占位）→ 旧版提示 /「先别更新」警示 → 主按钮（lg block）→［仍要下载］→ 来源行 → 备用网盘框 →（选电脑时）看电脑版提示。
3. 详情下载区下方广告（横幅）。
4. 标签栏（吸顶）。
5. 标签内容卡片。
6. 反馈卡。
7. 相关公告卡（有时）。
8. 大家还在看（横滑 `.sim`）。
9. 页脚；底部固定操作条 + 底栏。

电脑：
1. 面包屑（13px `--ink2`，下 16）。
2. 双栏：主栏纵向 gap 16：头部（图标 80，H1 30px，右侧收藏 + 分享按钮）→ 关键数字 → 结论条 → 标签栏（吸附 top 64）+ 内容（上 10）→ 反馈卡 → 相关公告 → 大家还在看。右栏：下载卡（标题「下载」，无「已自动识别」）含扫码区 → 侧栏广告。

### 5.5 公告列表（R-ANN-01）

- 手机：类型 chips（下 12）→ `.ac` 列表 → 页脚。
- 电脑（最大宽 820）：H1「群公告」→ 说明「重要通知、使用提醒和维护安排。」→ chips → 列表。

### 5.6 公告详情（R-ANN-03）

- 已结束提示 → 标签行（📌 置顶、类型、「10月14日发布 · 有效期到 10月21日 · 2,310 人看过」）→ H1（手机 22 / 电脑 30）→ 正文（段落 16px / 1.8，上下 12）→「相关软件」+ 精简更新卡（小图标、名称、「版本 · 日期」、建议标签）→「🔗 复制公告链接」描边整宽按钮（上 16）。
- 电脑：面包屑「群公告 › 详情」，正文包在 `.card` 中，内边距 28/32，最大宽 760。

### 5.7 搜索（R-SEARCH）

- 手机：顶栏为返回 + 搜索框；内容区：空查询 →「大家在搜」chips（换行，前 3 个带 🔥）→「最近看过」+「清空」+ `.rank` 样式列表（小图标、名称、简介、`›`）；有查询 →「软件 · N」精简卡列表 →「公告 · N」`.ac` 精简卡（标题 + 日期）；无结果 → 空状态。
- 电脑：最大宽 820；大搜索框（最小高 52、白底、描边）→ 上 18 → 结果区。

### 6.2 加载、错误、空状态

- 加载：列表和卡片使用与内容同尺寸的骨架（`#EEF1F6` 底、圆角同组件），不使用整页转圈；按钮提交中禁用并改文案。
- 错误：页面级「😵 加载失败了 / 请检查网络后重试」+ 次按钮「重试」；局部（反馈、提交）失败用 toast「提交失败，请稍后再试」，表单内容保留；429 显示「操作太频繁，请稍后再试」。
- 空状态：见 §4.11；页面 404「这个页面不存在」/ 软件下架「这个软件已下架」/ 公告撤回「这条公告已经撤回」，均提供「回首页」按钮。

### 6.3 键盘与焦点

- 全局 `:focus-visible { outline: 3px solid #8EAEFF; outline-offset: 2px }`，禁止去掉焦点样式。
- 卡片若为 `div`（如软件库卡）需 `tabindex="0"` + `role="button"`，Enter / Space 触发；卡片内的星按钮单独可聚焦且阻止冒泡。
- 标签栏、分段控件支持左右方向键；chips 组 `role="group"` + `aria-label`（如「按设备筛选」「分类」「选择设备」「选择版本」）。
- 弹层：打开后焦点进入，Tab 循环在弹层内，**Esc 关闭**，关闭后焦点回到触发元素；点遮罩关闭（点弹层内部不关闭）。
- 电脑导航搜索框输入后跳搜索页，焦点保留在搜索页输入框且光标在末尾。

### 6.4 点击区域

所有可点元素点击区 ≥ 44×44。视觉小于 44 的（chip 34、`.btn.sm` 32、收藏星 32、`.ib` 38、广告关闭 26、排序标签 21、`.vsel` 项、`.dtabs` 项约 36）通过透明内边距或 `::after { inset: -6px }` 扩展，相邻点击区不重叠。

### 6.5 滚动与状态保持

- 切换筛选、排序、设备、版本、标签页不重置滚动位置（手机选择版本记录中「下载这个版本」时平滑滚动到顶部）。
- 返回上一页恢复列表滚动位置。
- 设备 / 版本选择写入 URL（replaceState），分类、搜索词写入 URL。

## 7 文案规范

### 7.1 语气

- 对象是普通群友：口语、短句、直接告诉「该怎么做」。用「你」，不用「您」；称管理员为「群主」。
- 不用技术词：说「安装包」「下载」「装回去」，不说「APK」「回滚」「客户端」；版本号前不加「v」。
- 设备名：短名「安卓 / 苹果 / 电视 / 电脑」用于按钮、标签；全名「安卓手机 / 苹果手机 / 电视盒子 / 电脑」用于教程标题、常用设备、反馈弹层。
- 日期：前台「10月16日」，今天 / 昨天加后缀；后台可用「10-16 14:30」。
- 数字：≥ 1 万显示「1.2万」，否则千分位；估算值后台加「约」。
- 标点：中文全角标点；引用界面上的按钮用「」，引用说法用 “”（与设计稿一致）。
- 广告一律标注「广告」（不用「推广」）。

### 7.2 更新建议四档

| advice | 标签 | 结论条标题 | 群通知行 | 建议说明示例 |
| --- | --- | --- | --- | --- |
| recommended | ✓ 建议更新 | 建议更新 · 安卓版 3.2.1 | ✅ 建议更新 | 修复了播放卡顿，旧版也还能用，不着急。 |
| wait | ! 可以等等 | 可以等等 · 电脑版 5.9.3 | ⏳ 可以等等，不急 | 偶尔出现同步冲突，不急的话等下个版本。 |
| hold | ✕ 先别更新 | 先别更新 · 电脑版 4.1.0 | ⛔ 先别更新 | 4.1.0 有登录问题。还没更新的先别更新；已经更新的先用网页版，或者装回 4.0.6。 |
| optional | ○ 可选更新 | 可选更新 · 电脑版 1.14.2 | 🔘 可选更新，按需（设计稿未定义，待确认） | 被杀毒软件拦截的话再更新，其他情况可以不更新。 |

相关按钮文案：「⬇ 官方下载 {设备}版」「⬇ 去 App Store 下载」（底部条「⬇ 去 App Store」）「⬇ 下载稳定版 {x}」「仍要下载 {x}」；警示「⚠ {x} 有问题，建议先下载稳定版 **{y}**」；旧版提示「你正在看旧版本 {x}。没有特别需要，建议下载最新版 {y}。」；反馈「更新后能正常用吗？」「👍 能正常用」「👎 有问题」「{p}% 的群友反馈能正常使用」「问题较多，建议先等等」。

### 7.3 更新内容类型

新增（added）/ 修复（fixed）/ 优化（improved）/ 已知问题（known_issue）。条目以动词开头、不加句号，例如「新增 0.5x–2x 倍速播放」「修复部分机型播放卡顿」「启动速度提升约 30%」「部分账号无法登录（官方已确认，修复中）」。

- 手机 / 电脑差异使用媒体查询（§3.1），不使用设计稿的 `.d` 父类切换。
- 设计稿中的 `.row`、`.grow`、`.ell`、`.muted`、`.small`、`.xs`、`.mono` 工具类改为 `sv-u-*` 或组件内部样式。

- 广告组件沿用 `apps/web/components/station/ad-slot.tsx` 的位置标识，标签文字改为「广告」。

### 9.2 网站后台

- 沿用 `sa-` 前缀与现有 `apps/web/app/admin/station-admin.css`；新增后台样式继续以 `sa-` 命名（如 `sa-kpi`、`sa-todo`、`sa-slot`、`sa-notice`、`sa-side`）。
- 后台复用同一套 token 值（在后台根节点定义同名变量，或从共享 token 文件引入），保证与前台颜色一致；后台不使用 `sv-` 组件类，避免样式交叉。
- 发布更新 / 发公告弹层在后台实现，使用 `sa-sheet`，规格同 §4.9 电脑弹层。

### 9.3 小程序样式映射

- 源码：`apps/miniprogram`，样式写在 `app.wxss`（全局 token 与组件）与各页面 `.wxss`；构建脚本转换为小红书 `.css`。替换现有绿色主题（`#35664a`、`#f4f7f3` 等）。
