电脑端

用顶部的“跳转”可以同时切换电脑和左侧手机的页面，每个画面里也都能点击操作。“后台”页面只在电脑端提供，可用“跳转”里的“后台页面”下拉直接打开某个后台页面，后台里的修改会同步到前台画面。

页面清单 · 前台

  • 首页：本周概览、公告、收藏动态、分类、最新更新、热门
  • 软件库：分类、排序、收藏
  • 软件详情：结论、设备、版本选择、下载，以及更新内容、安装教程、常见问题、版本记录、软件信息五个标签页，还有反馈和同类推荐
  • 公告：列表、筛选、详情、关联软件
  • 搜索：热门、历史、结果高亮、找不到时提交想要的软件
  • 我的：收藏、最近看过、同步码、常用设备、提醒、反馈记录

页面清单 · 后台（电脑）

  • 工作台：今日数据、需要你处理、想要的软件、最近发布、广告位
  • 软件管理：列表、搜索、分类/状态筛选、上下架
  • 软件编辑：基本信息、slug 锁定、设备、图标主色、分设备安装教程、常见问题、截图
  • 版本管理：按软件 + 设备分组的版本列表、筛选
  • 版本编辑：更新建议四档、先别更新必选稳定版、分类更新内容、获取入口、实时群通知与卡片预览
  • 公告管理、用户反馈、想要的软件、广告管理、站点设置

弹层

  • 小红书内打开：图示引导，并提供复制链接
  • 分享：复制链接、群通知文案、分享海报
  • 反馈问题：选问题类型、补充说明
  • 同步码：生成，或在新设备上输入恢复
  • 想要的软件：用户提交
  • 后台抽屉：公告编辑、推广素材编辑
  • 后台弹窗：版本预览、把版本标为先别更新、收录想要的软件、修改密码

用户与收藏

  • 看和下载：永远不用登录
  • 收藏：点一下即可，保存在本机
  • 换手机：用同步码恢复收藏，不需要账号
  • 新版本提醒：需要登录，规划中

广告位

  • 首页列表第 3 条之后（手机和电脑）
  • 详情页下载区下方（手机）
  • 右侧栏 300×250（电脑首页和详情页）
  • 都标注“广告”；不放在下载按钮旁边；后台有总开关和每个位置的开关，可查看曝光和点击，推广素材可指定投放位置和起止时间
