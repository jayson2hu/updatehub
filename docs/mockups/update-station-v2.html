网盘备用

链接固定为 /u/软件-版本，以后在群里发过的链接都不会失效。

这一版解决的问题

  • 链接被聊天刷走 → 每条更新一个固定链接，首页可以查到全部
  • 不知道要不要更新 → 页面最上面直接给出“建议更新 / 可以等等 / 先别更新”
  • 设备该下哪个 → 自动识别设备，可以手动切换
  • 小红书里点了没反应 → 识别后引导“在浏览器打开”
  • 反复答疑 → 每款软件附安装教程和常见问题

下载规则

  • 主按钮只放官方链接（官网 / 应用商店）
  • 网盘只作为“备用”，放在虚线框里，带提取码一键复制
  • 本站不存放安装包

广告规则

  • 只出现在下载区之后，标注“广告”，可以关闭
  • 样式与下载按钮完全不同，不会被误点
  • 后台有总开关，默认关闭

这一版不做

  • 新人必装清单、帮你找软件
  • 用户账号、评论
  • 自动检测新版本（发布仍由群主人工确认）
