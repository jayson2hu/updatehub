① 站名

顶部可以切换候选名，看实际效果。站名在后台“站点设置”里修改，不需要改代码。

  • 新版来了：通知标题就是“新版来了：xx 3.2.1”（推荐）
  • 更了么：口语化，好记
  • 版本驿站 / 追新小站 / 软件新鲜事

② 电脑端

  • 默认识别为“电脑”，仍然可以切换设备
  • 下载手机版或电视版时显示二维码：手机扫码后在手机上下载
  • 电视版提示“下载到电脑，用U盘拷到电视”
  • 下载卡片固定在右侧，滚动时一直能看到
  • 手机上看电脑版时，提示“复制链接到电脑打开”

  • 都标注“广告”，手机端可以关闭
  • 不放在下载按钮旁边，也不用“下载”字样，避免误点
  • 接入广告联盟一般要求网站已做 ICP 备案

④ 用户

  • 不用注册：从群里点进来就能用，没有门槛
  • 关注软件：保存在本机，首页优先显示关注的软件更新，并显示红点
  • 常用设备：记住后，打开更新页直接显示对应设备
  • 更新反馈：“能正常用 / 有问题”，帮助其他人判断要不要更新，也帮你更快发现问题
  • 想要的软件：用户提交，群主在后台查看
  • 以后再做：登录同步、微信提醒（看后续需求）
