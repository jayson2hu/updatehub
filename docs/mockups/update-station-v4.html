页面清单

  • 首页：本周概览、公告、收藏动态、分类、最新更新、热门
  • 软件库：分类、排序、收藏
  • 软件详情：结论、设备、版本选择、下载，以及更新内容、安装教程、常见问题、版本记录、软件信息五个标签页，还有反馈和同类推荐
  • 公告：列表、筛选、详情、关联软件
  • 搜索：热门、历史、结果高亮、找不到时提交想要的软件
  • 我的：收藏、最近看过、同步码、常用设备、提醒、反馈记录
  • 后台工作台（电脑）

弹层

  • 小红书内打开：图示引导，并提供复制链接
  • 分享：复制链接、群通知文案、分享海报
  • 反馈问题：选问题类型、补充说明
  • 同步码：生成，或在新设备上输入恢复
  • 想要的软件：用户提交
  • 发布更新（后台）：表单 + 实时生成群通知

用户与收藏

  • 看和下载：永远不用登录
  • 收藏：点一下即可，保存在本机
  • 换手机：用同步码恢复收藏，不需要账号
  • 新版本提醒：需要登录，规划中

广告位

  • 首页列表第 3 条之后（手机和电脑）
  • 详情页下载区下方（手机）
  • 右侧栏 300×250（电脑首页和详情页）
  • 都标注“广告”；不放在下载按钮旁边；后台可以分别开关，并查看曝光和点击
