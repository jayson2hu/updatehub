更新小站 · 设计稿

解决的问题：软件更新通知在小红书群里被刷屏、找不到。
做法：群里只发一条链接，点进来看清楚「更新了什么、该不该升级、去哪里下载」。

  1. 管理员在后台发布版本或公告，点「复制群通知」
  2. 群里粘贴短消息和链接，不再刷长文
  3. 群友点开链接，直达这条更新，选自己的设备，拿到官方入口
  4. 以后想回看，随时在站里按软件或设备查
管理员点「复制群通知」后，粘贴到群里的内容：
【光幕影视 电视版 3.2.1 已更新】 修复卡顿，新增倍速播放。 建议：电视版用户可以升级，旧版仍能用。 查看详情与官方入口 👇 https://example.com/software/guangmu?d=tv

示例软件均为虚构，没有真实下载地址。点击页面里的按钮可以体验交互。
