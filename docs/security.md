# 安全边界

本文描述实现与运行前提，不替代生产安全审查。最新安全检测、修复与证据见 [2026-10-20 安全报告](security-review-20261020.md)，上线操作见 [容器部署交接](container-deployment-handoff.md)。旧报告仅作为历史记录。当前已完成隔离原生 PostgreSQL 数据库/图标恢复演练；Docker、生产 TLS、外部告警和生产负载验证尚未执行。正式首次上线为空内容，不迁移开发库/图片/账号，不执行 seed。

## 认证与权限

管理员密码以 Argon2id 散列存储。随机 session token 由 HttpOnly Cookie 保存，数据库仅保存其 SHA-256 散列；生产启用 Secure，Cookie 使用 SameSite。会话有到期时间，退出会撤销对应会话。

管理写操作验证登录状态、CSRF token 和可信来源。所有后台权限检查位于 API。公开 API 只返回已发布的软件、公告与帮助内容，关联软件下线后不再暴露对应内容或合集成员；通过 ID 或 slug 猜测未发布内容不能绕过检查。不存在普通用户账号或多级管理员角色。

登录和公开读取具备进程内限流，重启会清空计数。当前部署必须保持单 API 进程。增加 worker 或副本之前，需要共享限流存储，并检查所有实例的一致会话与审计行为。

## 内容与跳转

输入通过 Pydantic 模型验证，数据库查询使用 SQLAlchemy 参数化操作。详情文字按文本展示，不接受管理员提供的任意可执行 HTML。

现行 station 入口 URL 支持 HTTP/HTTPS，拒绝危险协议、用户信息段、非法端口、空白及反斜线；旧 API 的 HTTPS/公网地址规则更严格，且默认关闭。公开入口来自已发布内容，不接受任意 `next` 跳转。URL 合法并不等同来源可信；域名归属与实际页面需要管理员人工确认。本站只维护通知与入口，不会主动抓取 URL，不提供下载代理、远程图标抓取、安装包或音频中转。若后续实现链接巡检，必须再增加 DNS 解析结果校验、连接地址固定及逐跳重定向校验。

运营分析只保存按日聚合的搜索词、搜索次数、无结果次数及官方入口点击，不保存 IP、Cookie、会话或匿名访客 ID；它不构成独立访客/转化率统计。管理员可看到搜索词汇总，因此隐私页提醒用户不要在搜索框输入密码或个人资料，服务端也会过滤明显的敏感格式。备份会包含这些汇总及管理员散列、会话和审计，应按部署文档限制读取与加密异地保存。恢复脚本会清除恢复库的历史管理员会话。

图标只接收 PNG/JPEG/WebP，并验证可解码内容与大小，重新编码后使用随机文件名保存。上传目录不执行脚本；不支持 SVG。数据库和文件系统仍需定期备份，首轮没有自动孤儿文件清理。

## 部署前提

- 生产仅通过 Caddy HTTPS 进入服务；数据库与 API 不公开端口。开发端口仅绑定本机回环地址。
- 代理转发头只应来自受控的 Web/Caddy 链路。当前容器内 Uvicorn 信任代理头，成立前提是 API 仅位于私有容器网络。不要单独公开 API 端口。
- API 与 Web 以非 root 用户运行；生产文件系统只读，图标卷与临时目录单独可写。
- Caddy 设置 HSTS、禁止 MIME 嗅探、点击劫持与权限策略。Next.js 设置基础 CSP，但为框架兼容保留 inline script/style；尚未引入 nonce 严格策略，应在完整页面回归之后进一步收紧。
- `.env` 不能提交版本库；密码与 Cookie 不应写入日志、截图或审计载荷。初始管理员密码用完即移除。
- PostgreSQL 首轮使用容器初始化用户运行迁移和应用；生产进一步加固可拆分迁移用户与最小权限应用用户，拆分前需验证所有查询和迁移。

## 代理身份边界

生产配置仅公开 Caddy，Web/API 必须保持在容器私有网络。Caddy 覆盖浏览器提供的 `X-Forwarded-For`，Next.js 在服务端读取目录时传递该地址，使不同访问者不共用搜索限流额度。API 的 `--forwarded-allow-ips='*'` 仅适用于这种完全隔离的代理网络，不能用于直接公开的 API。若接入其他 CDN，需重新配置并验证可信代理链。
