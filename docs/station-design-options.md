# 更新小站：三套前端审查方案

三套方案都读取同一份软件、版本和公告数据，提供首页、目录、详情和公告的完整访问路径。入口 `/designs`；A、B、C 的入口分别为 `/designs/a`、`/designs/b`、`/designs/c`。顶部审查栏支持在同一页面切换方案。

## A · 清晰直达

面向普通群友，沿用熟悉的手机应用阅读和操作习惯，减少首次访问的判断成本。白色内容区、清楚的设备标签、独立操作入口；桌面用紧凑的软件直达侧栏。

颜色：白 `#FFFFFF`、雾蓝 `#F5F7FB`、深蓝文字 `#18243B`、次要文字 `#626D80`、品牌蓝 `#245BDD`、边线 `#E3E9F2`。

字体：苹方、微软雅黑、系统无衬线。手机标题 28px，正文 16px，版本与设备 13–14px。圆角 8/12/16px，图标 48/56px。统一左对齐。

```text
品牌 + 主导航
最新软件更新              免登录 / 设备适配
置顶提醒
搜索 + 设备页签           软件与最新版本直达
日期 / 图标 / 版本
摘要 / 查看更新           安装前小提示
```

## B · 更新手册

以真实发布记录为视觉主体，像长期可查阅的版本手册。日期在桌面独立成列，名称、版本、设备严格对齐；减少容器嵌套，适合更新频繁和喜欢迅速浏览的群友。

颜色：冷白 `#F7F9FC`、白 `#FFFFFF`、深墨蓝 `#18243B`、次要文字 `#626D80`、记录蓝 `#315DB8`、结构线 `#D9E2EF`。

字体：微软雅黑、苹方、系统无衬线。标题 40/28px，正文 16px，版本使用等宽数字。圆角 6/10px，轻阴影关闭。统一左对齐。

```text
品牌 / 最新 / 软件 / 公告
更新手册                 最近发布日期
重要公告
搜索 + 设备筛选
日期列  软件 / 版本 / 设备     软件索引
        更新说明 / 入口       安装与查阅说明
```

## C · 蓝色社区

为群入口建立更鲜明的蓝色品牌，用深蓝首屏区域和真实软件更新形成记忆点。桌面更新为按日期分组的双列信息卡，手机仍是单列；将软件获取与未来推广区域保留清楚区分。

颜色：浅蓝背景 `#F1F5FD`、白 `#FFFFFF`、深蓝 `#173B79`、主文字 `#18243B`、品牌蓝 `#245BDD`、边线 `#DEE7F7`。

字体：苹方、微软雅黑、系统无衬线。标题 42/28px，正文 16px，软件名称 19/18px。圆角 12/18/22px，图标 52/64px。统一左对齐。

```text
品牌 + 导航
深蓝用途标题              真实最近更新卡
置顶公告
搜索 + 设备筛选           软件图标入口
日期
更新卡 | 更新卡           第一次使用的步骤
```

## 设计取舍

建议优先选择 A：它与「群内点击 → 找软件 → 选设备 → 获取」的路径最贴合。B 更适合更新量大、经常回来查版本的用户；C 的品牌感更强，也便于以后承载独立推广内容，但需要控制首屏高度。

审查前已修正通用模板倾向：A 直接进入查找任务，不再放大型宣传卡；B 的日期结构对应实际版本记录，采用适合中文阅读的无衬线字体；C 的主视觉使用真实软件与版本，不添加与更新无关的插画或装饰数字。所有方案保留有效公告、示例标记、不可用说明、广告开关和真实数据接口。

## 预览与维护

方案组件：`apps/web/components/station/design-home.tsx`。方案配置与取舍：`apps/web/lib/design-options.ts`。独立样式：`apps/web/app/station-variants.css`。软件、更新记录和公告继续使用共用组件与接口。

审查栏支持在相同软件或公告页面切换方案，并保留设备参数。软件侧栏直达与版本号标注同一平台，避免电视版本号与手机版入口混淆。对比页显示真实浏览器截图，支持手机/电脑切换；暂选保存在当前浏览器，正式采用哪套由后续选择决定。

对比截图：`apps/web/public/design-previews/`。重新生成截图及验证可运行：

```powershell
apps/api/.venv/Scripts/python.exe scripts/station-options-check.py
```

## 实际验证

2026-10-13，在本机 Microsoft Edge 中检查三套方案的首页、软件目录、软件详情、公告列表、已结束公告详情，各覆盖 1440×1000、390×844、360×800。对比页两种截图模式也在上述尺寸下检查。

21 组验证通过：别名搜索、筛选与无结果恢复、带方案的分享直达及刷新、版本标题定位避开审查栏、平台版本与入口一致、换方案保留设备、复制拒绝时手动回退与键盘焦点、底部获取栏不遮正文、触控区域、公告到期标记、截图正常加载、暂选刷新后保留、不存在页面恢复。

截图检查发现 B/C 首屏过高，已压缩重复标题及留白，保留正文与 44px 操作区域；三套手机首页现在均完整展示首条更新。没有横向溢出或未处理的浏览器脚本异常。代码规范、TypeScript 与正式构建通过。

本轮没有发布或修改站点数据，前后公开数据完全一致：6 款软件、11 条更新、4 条公告，广告关闭。结果及实际截图保存在 `artifacts/design-options/`。
