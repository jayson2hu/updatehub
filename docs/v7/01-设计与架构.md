## 1 目标与范围

把访客前台（手机与电脑网页）换成「软萌喵」风格：暖桃色底、白色圆角卡片、猫咪吉祥物、「群主说」聊天气泡、双列软件卡片、悬浮胶囊底栏，白天 / 黑夜 / 跟随系统三种外观。

- **在范围内**：前台全部页面（首页、软件库、搜索、软件详情、公告列表与详情、我的、关于、状态页）的视觉与布局；结论文案的前台用语；电脑宽屏适配。
- **不改**：数据模型、API、路由与 URL、广告位与统计、同步码、反馈逻辑、v6 已完成的后台（简化发布、后台外观）。后台只同步品牌色，不改布局。
- **不做**：小程序（另行排期）。

## 2 视觉规范

### 2.1 颜色令牌（与原型一致）

| 令牌 | 白天 | 黑夜 | 用途 |
| --- | --- | --- | --- |
| `--sv-bg` | `#FFF6EF` | `#1E1612` | 页面底 |
| `--sv-card` / `--sv-surface` | `#FFFFFF` | `#2B211B` | 卡片、输入框、顶栏按钮 |
| `--sv-ink` | `#3B2A20` | `#F6E9DF` | 主文字 |
| `--sv-ink2` | `#7A5C4B` | `#C9AE9C` | 次要文字 |

主按钮用「橘色底 + 深色字」，不用白字（白字对比只有 2.6:1）。

### 2.2 形状与排版

- 圆角：卡片 24px，结论卡 28px，按钮 / 输入框 / 筛选胶囊为胶囊形（999px），软件图标 16px。
- 卡片不加描边、不加阴影，靠白卡与桃色底的明度差区分层级；黑夜同理。
- 字号：页面标题 22px/800，区块标题 19px/800，卡片标题 16px/800，正文 15–16px，辅助 13px。
- 结论前台用语：建议更新 →「放心更新」，可以等等 →「等等再说」，先别更新 →「先别更新」（仅前台展示，后台与群通知仍用原词）。
- 猫咪吉祥物：内联 SVG，三种表情对应三种结论（开心 / 犹豫 / 担心）；空状态、反馈成功等提示使用口语化文案，但不影响信息准确。
- 外观：沿用 v6 的 `html[data-theme]` 机制（跟随系统 / 白天 / 黑夜），只替换令牌值。

## 3 页面结构

| 页面 | 手机（< 768px） | 电脑（≥ 1024px） |
| --- | --- | --- |
| 顶栏 | 猫咪 + 站名 + 一句话副标题（首页：「今天有 N 个更新，M 个要小心喵」）+ 外观图标 | 横向导航：猫咪站名、四个入口、搜索框、外观图标 |
| 首页 | 搜索入口 → 群主说（公告气泡）→ 本周新版本（设备筛选胶囊 + 双列软件卡片）→ 广告位 → 分类 | 左：本周新版本（三列卡片）；右栏：群主说气泡、我关注的、侧栏广告 |
| 软件详情 | 居中软件头 + 设备胶囊 → 猫咪结论卡 → 主按钮 / 次按钮 → 安装步骤 → 改了什么 → 反馈 → 历史 → 常见问题 → 信息 | 左栏同手机顺序；右栏吸顶：设备胶囊、下载、扫码 |
| 软件库 / 搜索 | 圆角搜索框 + 分类胶囊 + 双列卡片 | 三列卡片 |
| 公告 | 「群主说」聊天气泡列表；详情为气泡段落 | 居中单栏，最大宽 760px |
| 我的 | 关注列表卡、同步码卡、外观设置 | 两栏 |
| 底栏 | 悬浮深色胶囊，当前项为橘色胶囊 | 不显示 |

## 4 技术架构

- **不新增依赖、不改数据流**：页面仍由 `app/*/page.tsx` 服务端取数（`lib/station.ts`），组件在 `components/station/*`。
- **样式**：继续使用 `app/station-v4.css` 的 `.sv-site` 作用域与 `--sv-*` 令牌。v7 改令牌值，新增少量 `sv7-*` 结构类；黑夜令牌在同文件的 `html[data-theme]` 块中。
- **新增组件**：`components/station/cat.tsx`（猫咪 SVG，`mood: 'ok' | 'wait' | 'bad'`），`ChatBubble` 公告气泡（cards.tsx）。
- **前台用语**：`lib/station-view.ts` 增加 `friendlyAdvice` 映射，只在前台组件使用；`adviceMeta` 保持不变，避免影响后台与群通知文案。
- **兼容**：URL、`data-route`、广告位 `placement`、测试脚本依赖的类名（`.sv-release-card`、`.sv-tabbar` 等）保持不变，只改样式与内部结构。

## 5 开发流程

1. 每个小功能一个本地提交，提交前跑 `npm run lint` 与 `npm run typecheck`，并在浏览器（`http://127.0.0.1:3010`）按 390 / 1280 宽度、白天 / 黑夜检查对应页面。
2. 每次提交后更新 [02-开发进度](02-开发进度.md)：完成项、提交号、检查结果、遗留问题。
3. 全部完成后按 [03-验收](03-验收.md) 跑全量验收并记录结果；推送与合并由用户决定。
