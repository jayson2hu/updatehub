# 更新小站 · 微信小程序

本目录同时作为微信与小红书的共用源码。运行 `npm run mini:build` 后导入两个独立生成项目；完整双平台说明见 [小程序开发与发布](../../docs/station-miniprograms.md)。

原生微信小程序，无需额外安装前端依赖。与网站共用 FastAPI / SQLite、管理员发布内容和上传图片；小程序不保存另一份内容，也不暴露管理入口。

## 本地启动

1. 先按 [站点运维说明](../../docs/station-operations.md) 启动 API（8010）与网站（3010）。已有服务正常运行时无需重启。
2. 在微信开发者工具中「导入项目」，目录选择 `D:\fayun\code\updatehub\apps\miniprogram`。
3. 使用自己的小程序 AppID；当前 `touristappid` 仅作为开发导入占位。工具版本不接受游客身份时请填测试号或开发号。
4. `config.js` 的 `develop` 已指向本机。开发工具中启用「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」，此开关仅用于本地调试。
5. 编译进入「最新」，可搜索、筛选设备、打开软件详情、切换版本、查看公告；修改后台内容后下拉刷新。

真机预览不能访问电脑的 `127.0.0.1`。应使用测试 HTTPS 服务，或将开发配置改为电脑的局域网地址并在受信任的局域网内配置服务监听和防火墙。发布配置不能沿用本机地址。

## 页面与功能

| 页面 | 路径 | 内容 |
| --- | --- | --- |
| 最新 | `pages/latest/index` | 置顶公告、软件/别名搜索、设备筛选、按日期更新 |
| 软件 | `pages/software/index` | 软件目录、设备、状态 |
| 软件详情 | `pages/detail/index?slug=guangmu&platform=tv` | 多平台、多版本、安装方法、FAQ、分享、获取链接 |
| 公告 | `pages/announcements/index` | 分类、置顶、有效与已结束状态 |
| 公告详情 | `pages/announcement/index?slug=...` | 正文、图片、相关链接、关联软件、分享 |

详情页分享会保存当前设备与版本。网站链接复制后也包含这两个选择，打开或刷新能回到对应版本。微信原生分享需要配置真实 AppID 后在微信中体验。

## 获取链接

外部网盘、官网和安装包地址通过「复制安卓版获取链接」「复制电视版获取链接」提供；提取码和备用链接分别维护。小程序不自动唤起外部浏览器，不把任意外链塞进 `web-view`。用户复制后自行在浏览器粘贴打开。剪贴板失败时显示可长按选择的手动复制面板。

未配置地址、软件不可用、版本不可用时均没有可执行获取入口。页面明确标注示例内容。正式上线后由同一管理后台维护真实链接。

## 配置与发布

- `project.config.json`：填写真实 AppID。
- `config.js`：`trial` / `release` 分别填写真实 HTTPS API 与网站域名；留空时显示明确配置错误，避免线上误连本机。
- 微信公众平台：配置 `request` 合法域名；图片域名按实际用途加入 `downloadFile` 合法域名。确认 HTTPS 证书、备案与账号资质满足微信平台要求。
- 如将来使用 `web-view`，需要具备对应账号能力并单独配置业务域名；本版不依赖它。
- 真机检查 iOS / Android、小屏字体、分享回流、图片、剪贴板失败、弱网与下拉刷新，然后通过开发者工具上传体验版并提交平台审核。

当前运行环境未安装微信开发者工具，未进行微信模拟器编译、扫码预览或平台提审。已进行共享真实接口的页面逻辑与配置检查；详见 `docs/station-design-50.md` 的验证记录。正式提审与上架需要站主账号和域名配置。

## 广告扩展

`components/ad-slot` 是独立组件，读取现有推广配置及全站广告开关，使用 `home_feed` / `detail_body` 两个位置；默认关闭，无空白占位。推广图片预留比例、延迟加载，失败收起。活动起止时间、启停与图片故障不会影响软件版本与获取链接；推广按钮写「复制活动链接」，与获取软件按钮分开。

将来接微信原生广告时，可在这个组件内接入平台 `ad` 组件和独立广告单元ID，保留统一开关，不改软件版本数据。原生广告、投放统计与平台审核不在本版接入范围。

## 数据与备份

小程序仅作读取入口，数据持久化仍由现有服务器完成。备份 `runtime/station.db`、`runtime/station-uploads` 与服务器环境配置；账号密钥不放入小程序。发布小程序不会重置站点内容。
